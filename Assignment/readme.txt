구현한 내용:

컴그 숙제 리드미

화면에 바닥 그리기
g, G: 가로, 세로 입력받아 육면체 그리기
육면체 나타나는 애니메이션
	탑뷰 미니맵 뷰포트 

키보드 명령어:

o/p: 투영 선택한다 (직각/원근)
z/Z: 원근투영시 z축으로 이동할 수 있게 한다
m/M: 육면체들이 위, 아래로 움직인다/멈춘다
y/Y: 카메라가 바닥의 y축을 기준으로 양, 음 방향으로 회전한다.
	r: 미로를 제작한다. (칸의 육면체가 사라지고 미로가 생긴다.
v: 육면체들 움직임이 멈추고 낮은 높이로 변한다.
	s: 미로에서 객체가 나타난다.
	화살표키보드: 객체 앞뒤좌우 이동
	+/-: 객체의 이동속도 증감
	1/3: 카메라 시점 1인칭, 3인칭 변환
	c: 모든 값 초기화
q, Q: 프로그램 종료

키보드 명령어 콘솔창 출력
